# 🚀 React Component Library

A curated collection of reusable React components built as part of a daily challenge to strengthen core React fundamentals, state management, and modern UI practices.

---

## 🛠️ Tech Stack

* **Library:** React
* **Language:** JavaScript (ES6+)
* **Build Tool:** Vite
* **Styling:** CSS3

---

## 📅 Project Progress

| Day | Component | Key Features / Practice |
| :--- | :--- | :--- |
| **Day 1** | **Accordion** | Interactive Q&A list for React interview prep. Practiced components, state, and toggles. |
| **Day 2** | **Todo App** | Complete task manager with task persistence using `localStorage`. |
| **Day 3** | **Counter** | Interactive counter featuring increment, decrement, and reset functions. |
| **Day 4** | **Color Picker** | Real-time color switcher updating UI dynamically based on user selection. |
| **Day 5** | **Password Generator** | Customizable password creator with length, character criteria, and copy options. |
| **Day 6** | **Digital Clock** | Live-updating clock with real-time display, formatted using JS Date methods. |
| **Day 7** | **Quote Generator** | Generates random inspirational quotes with an option to display a new quote on demand. Practiced API integration, asynchronous data fetching, loading states, and error handling. |

## 🧩 Component Breakdown

### 🔹 Day 1: Accordion
A collapsible component designed to display React interview questions neatly.

* **Key Features:** Collapsible panels, dynamic toggle state.
* **Concepts Practiced:** `useState`, Props, Conditional Rendering, Event Handling, Component Reusability.

---

### 🔹 Day 2: Todo App
A simple task management tool to keep track of daily goals.

* **Key Features:** Add/delete items, mark complete, persistent storage across page reloads, Keyboard shortcut (`Enter` to submit).
* **Concepts Practiced:** `useState`, `useEffect`, Local Storage integration, Event Handling.

---

### 🔹 Day 3: Counter App
A state management utility highlighting basic reactivity.

* **Key Features:** Incremental/decremental adjustments, step controls, reset capability.
* **Concepts Practiced:** State updates, derived state, button event handling.

---

### 🔹 Day 4: Color Picker
An interactive color selection tool with instant visual feedback.

* **Key Features:** Hex/RGB value selection, live background color updates, click-to-copy code.
* **Concepts Practiced:** Controlled inputs, dynamic CSS styling in React.

---

### 🔹 Day 5: Password Generator / Picker
A utility tool for generating strong, random passwords.

* **Key Features:** Custom parameter selection (length, digits, special characters), instant copy-to-clipboard.
* **Concepts Practiced:** Complex conditional logic, custom helper functions within React hooks.

---

### 🔹 Day 6: Digital Clock
A real-time clock component that updates every second without a page refresh.

* **Key Features:** Live time display (HH:MM:SS), 12/24-hour format toggle (if you added one), smooth re-renders.
* **Concepts Practiced:** useEffect with setInterval, cleanup functions to prevent memory leaks, Date object formatting.

--- 

### 🔹 Day 7: Quote Generator

A simple quote generator that fetches and displays random inspirational quotes dynamically.

* **Key Features:** Generate a new random quote, display quote author, loading state, and error handling.
* **Concepts Practiced:** useState, useEffect, API integration, fetch, asynchronous JavaScript, conditional rendering, and error handling.
* **React Concepts:** Managing API response data, handling loading/error states, and triggering UI updates based on state changes.
